# Sample datasets

Generated by `python sample_data/make_sample_data.py`. Concentrations come
from the closed-form models in `pkpd/pk/compartmental/models.py` with the
true parameters listed below, plus fixed-seed 7% proportional noise — so
every file has a right answer to check results against.

Regeneration is byte-identical. If a file changes, that is a real change and
should be reviewed as a diff.

Used by the app sweep (`python -m tests.app_sweep`), and fine to open by hand
in the app.

| File | True parameters | What it exercises |
|---|---|---|
| `01_iv_bolus_postdose.csv` | k=0.15/hr, V=10 L, CL=1.5 L/hr | First sample at t=0.25, so C0 back-extrapolation runs |
| `02_iv_bolus_t0.csv` | same | Already has t=0, so no insertion happens |
| `03_extravascular.csv` | ka=1.2/hr, k=0.15/hr, V/F=30 L, Tmax≈1.98 hr | Absorption limb — pre-Tmax λz exclusion, zero inserted at t=0 |
| `04_iv_infusion.csv` | k=0.2/hr, V=15 L, CL=3.0 L/hr, Tinf=2 hr | MRT must lose Tinf/2; the only file with `infusion_duration` set |
| `05_multi_subject.csv` | 6 subjects, k 0.10–0.22, V 8.5–12 L | Subject combo switching, per-profile analysis |
| `06_steady_state.csv` | k=0.15/hr, V=10 L, Tau=12 hr | Trough-to-trough; Cmin insertion and the steady-state block |
| `07_with_weight.csv` | 3 subjects, weights 58/70/91 kg | Per-kg parameters, Manual mode weight column |
| `08_messy_headers.xlsx` | same as 01 | Columns named `ID`/`Time`/`Conc` — import wizard mapping |
| `09_bql_missing.csv` | same as 01 | A blank, a `BQL` and a `<LLOQ` cell — all must coerce to NaN and be excluded (`n_excluded=3`) |
| `10_edge_cases.csv` | — | Single-point, all-missing, flat, two-point and never-declining profiles |
| `11_invalid.csv` | — | Duplicate times, negative time and concentration, text, bad route — every validation path |
| `12_large.csv` | 50 subjects × 200 points | 10,000 rows, for measuring UI-thread stall |

Units for every file are **mg/L concentration, hr time, mg dose**, so
clearance reads in L/hr and volumes in L. Set those in the Data tab before
running, or the numbers will be labelled in whatever is selected.

Note that `10` and `11` are meant to produce warnings and rejections. A run
against them that reports no problem is itself the bug.
